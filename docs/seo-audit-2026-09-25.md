# MetaliQ Art SEO Audit

Audit date: 25 September 2026  
Storefront: https://metaliq.art

## Crawl baseline

- Shopify sitemap is available and references 131 storefront URLs: the homepage, 113 products, 13 collections, 3 pages, and the blog index.
- `robots.txt` allows public catalog content and points to the sitemap.
- HTTP and `www` correctly redirect to the canonical HTTPS non-`www` domain.
- Tested product, collection, page, blog, search, and homepage templates each render one H1.
- Tested public pages render canonical URLs and no rendered image was missing an `alt` attribute because the theme provides fallbacks.
- Product pages output Shopify ProductGroup data and breadcrumb structured data.
- A Google `site:metaliq.art` search returned no results during this audit. This is a discovery warning, not proof of a penalty; Search Console is the authoritative source.

## Fixed in the theme

- Replaced the generic homepage title with `Metal Wall Art in Pakistan | MetaliQ Art` when no custom Shopify SEO title is set.
- Stopped the theme from adding `MetaliQ Art` when a resource SEO title already includes `MetaliQ`.
- Added useful fallback descriptions for the homepage, About, Contact, Ordering & Payments, Blog, and other pages with no Shopify SEO description.
- Added a branded fallback Open Graph/Twitter image and image alternative text.
- Added explicit robots directives. Search, cart, customer, password, 404, empty-blog, and empty-collection pages no longer request indexing.
- Added `max-image-preview:large` and unrestricted snippet/video preview directives to indexable pages.
- Added article structured data through Shopify's native `structured_data` filter.
- Expanded Organization data with an international phone format, business description, service area, contact point, and languages.
- Added product availability to Open Graph product metadata.
- Added the phrase `metal wall art` to the visible homepage opening copy without changing the approved H1.
- Removed a duplicate heading-font declaration when the selected font is already weight 700.
- Changed the below-the-fold custom-design video from metadata preload to no preload.

1. Open Google Search Console, verify `https://metaliq.art`, submit `https://metaliq.art/sitemap.xml`, and request indexing for the homepage plus the main collection pages.
2. In **Products > Tree of Life Woman Face Metal Wall Art > Search engine listing**, replace the copied Lily Flower SEO title and description. This product currently duplicates the Lily Flower listing metadata.

4. Update product descriptions in Shopify Admin. The public catalog feed found 70 descriptions containing `Ready to hang out of the box` and 35 containing `without fading or chipping`. The theme cleans these statements on the visible PDP, but Shopify's native product structured data still uses the original Admin description.

### Priority 1: image and page metadata

1. Add descriptive source alt text to product media in Shopify Admin. The catalog feed contains 391 image records with blank source alt text across 113 products. The theme fallback prevents empty rendered alt attributes, but unique source text is better for image search and accessibility.
2. Set custom Shopify search-engine descriptions for About, Contact, Ordering & Payments, and the Blog. Theme fallbacks now cover them, but Admin metadata should remain the source of truth.
3. Rename the empty blog from `News` to a useful topic such as `Metal Wall Art Ideas`, then publish useful content before asking Google to index it. The theme automatically noindexes the blog while it is empty.
4. Review every product's Search engine listing preview for a unique title of roughly 45-60 characters and a useful description of roughly 120-160 characters.

### Priority 2: content growth

1. Publish buyer-intent guides: choosing wall-art size, installing metal wall art, styling office walls, and maintaining powder-coated steel.
2. Link each guide to the most relevant collection and 3-5 products; link those collection pages back to the guides where useful.
3. Add genuine product-specific Judge.me reviews. Do not add fabricated reviews or rating schema.
4. Connect Bing Webmaster Tools through Search Console import and submit the same sitemap.

## Validation notes

- Lighthouse against the local Shopify preview scored SEO 100, Accessibility 100, Best Practices 54, and Performance 36. The SEO and accessibility checks are useful; the other two scores are not production baselines because the preview runs over HTTP with Shopify hot reload, development analytics, Shop Pay framing errors, and a slow local proxy. Google PageSpeed Insights returned a rate-limit response, so production Core Web Vitals should be checked again after deployment.
- The local Lighthouse trace reported zero cumulative layout shift. Its 5.9-second LCP was primarily local preview time-to-first-byte plus render delay, while most blocking work came from Shopify platform/development scripts rather than the theme bundle.
- The automated full-site crawl triggered Shopify bot protection on 14 concurrent requests. Those responses were excluded from metadata conclusions and are not treated as broken pages.
- Shopify's generated `robots.txt` should remain platform-managed; no custom template is required.
